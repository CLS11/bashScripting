# Bash Scripting

Welcome to the **bashScripting** repository! 

This repo contains a collection of practical **Bash scripts** aimed at automating routine tasks, simplifying workflows, and enhancing productivity in Linux environments. Whether you’re a beginner learning shell scripting or an intermediate user looking for handy scripts, this repo has something for you.

---

## Features

- Useful automation scripts for system maintenance and file management  
- Examples of bash scripting concepts: variables, loops, conditionals, functions  
- Scripts designed to run smoothly on Linux terminals (tested on Ubuntu & Arch)  
- Modular and easy-to-understand code for quick customization

---

## Repository Contents

| Script Name           | Description                                       |
|----------------------|-------------------------------------------------|
| `backup.sh`           | Automated backup of important directories       |
| `cleanup.sh`          | Cleanup temporary and cache files to free space |
| `user_management.sh`  | Manage users: add, delete, or list users        |
| `monitor.sh`          | Simple system resource monitoring                |
| `file_search.sh`      | Search files by name or extension                 |
